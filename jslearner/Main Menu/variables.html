Variables in JavaScript

Variables are containers for storing data values. Think of them as labeled boxes where you can keep information to use later in your code.[reference:1]

Declaring Variables

In JavaScript, there are three ways to declare a variable:

  • let - For values that can change (recommended for most cases)
  • const - For values that never change (constants)
  • var - The old way (avoid in modern JavaScript)
// Variable declarations
let name = "John";      // String variable
const PI = 3.14159;     // Constant (cannot be changed)
let age = 25;           // Number variable
let isStudent = true;   // Boolean variable

Variable Naming Rules

  • Names can contain letters, digits, underscores, and dollar signs
  • Names must begin with a letter, $, or _
  • Names are case-sensitive (myVar and myvar are different)
  • Use camelCase for multi-word names: firstName, myAge
