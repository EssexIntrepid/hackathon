Boolean Logic

Boolean values represent one of two states: true or false. They're the foundation of decision-making in programming.[reference:7]

Comparison Operators

These operators compare values and return boolean results:

  • == - Equal to (checks value only)
  • === - Strictly equal to (checks value AND type)
  • != - Not equal to
  • !== - Strictly not equal to
  • > - Greater than
  • < - Less than
  • >= - Greater than or equal to
  • <= - Less than or equal to

Logical Operators

Combine multiple boolean expressions:

  • && - AND (true only if BOTH are true)
  • || - OR (true if AT LEAST ONE is true)
  • ! - NOT (reverses the boolean value)

Examples

let x = 10;
let y = 5;

console.log(x > y);      // true
console.log(x === 10);    // true
console.log(x === "10");  // false (different types)

let isRaining = true;
let hasUmbrella = false;

console.log(isRaining && hasUmbrella);  // false
console.log(isRaining || hasUmbrella);  // true
console.log(!isRaining);                 // false
