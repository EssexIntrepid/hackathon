Loops in JavaScript

Loops allow you to execute a block of code multiple times. They're perfect for repeating tasks or working with lists of data.[reference:6]

The for Loop

The most common loop. It has three parts: initialization, condition, and increment:

for (let i = 0; i < 5; i++) {
    console.log("Count: " + i);
}
// Output: Count: 0, Count: 1, Count: 2, Count: 3, Count: 4

The while Loop

Continues as long as a condition is true:

let count = 0;
while (count < 3) {
    console.log("Number: " + count);
    count++;
}

Looping Through Arrays

Loops are great for working with arrays (lists of items):

let fruits = ["Apple", "Banana", "Orange", "Mango"];

for (let i = 0; i < fruits.length; i++) {
    console.log("I like " + fruits[i]);
}
