JavaScript Data Types

JavaScript is a dynamically typed language, meaning variables can hold different types of values. There are 8 basic data types in JavaScript.[reference:2]

Primitive Data Types

String

Text values enclosed in quotes (single or double):

let greeting = "Hello, World!";
let name = 'John Doe';

Number

Both integers and floating-point numbers:

let age = 25;
let price = 19.99;
let negative = -10;

Boolean

Only two values: true or false:

let isLoggedIn = true;
let isComplete = false;

Undefined

A variable that has been declared but not assigned a value:

let something;
console.log(something); // undefined

Null

Represents "nothing", "empty", or "value unknown":

let emptyValue = null;

The typeof Operator

Use typeof to check the data type of a variable. It returns a string indicating the type.[reference:3]
