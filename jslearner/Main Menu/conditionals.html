Conditional Statements

Conditional statements allow your code to make decisions and execute different blocks of code based on whether a condition is true or false.[reference:5]

The if Statement

The if statement executes a block of code if a condition is true:

let age = 18;

if (age >= 18) {
    console.log("You are eligible to vote!");
}

The else Statement

Use else to execute code when the condition is false:

let temperature = 25;

if (temperature > 30) {
    console.log("It's hot outside!");
} else {
    console.log("It's comfortable outside!");
}

The else if Statement

Chain multiple conditions together:

let score = 85;

if (score >= 90) {
    console.log("Grade: A");
} else if (score >= 80) {
    console.log("Grade: B");
} else if (score >= 70) {
    console.log("Grade: C");
} else {
    console.log("Grade: F");
}
